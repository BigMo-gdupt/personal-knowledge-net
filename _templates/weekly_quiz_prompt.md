# 学术周提问 Prompt 模板

## 使用说明
此模板供 SOLO 定时任务使用，每周一自动读取知识库内容，生成学术思考题并发送邮件。

## 出题规则

### 结构比例（3:3:1）
- **基础巩固** × 3：围绕已读论文和 wiki 节点的基础概念理解
- **适度挑战** × 3：结合基础知识延伸到未读的前沿方向，引导探索
- **前沿思考** × 1：对标顶会论文级别的开放性问题

### 题目要求
1. 每道题必须**关联至少一个 wiki 节点**（用 [[节点名]] 标注）
2. 题目必须与**乙烯裂解炉炉管温度检测**或**深度学习时序方法**相关
3. 避免重复之前已出过的题目方向
4. 基础题要求有明确的知识点指向，挑战题要求开放但有引导，前沿题要求有创新空间

### 输出格式
```
## 📝 第 X 周学术思考题

### 🔰 基础巩固
**Q1. [题目标题]**
[题目内容，包含具体的问题引导]
> 关联：[[节点1]]、[[节点2]]

**Q2. ...**

**Q3. ...**

### 🚀 适度挑战
**Q4. [题目标题]**
[题目内容]
> 关联：[[节点]]

**Q5. ...**

**Q6. ...**

### 🔬 前沿思考
**Q7. [题目标题]**
[题目内容]
> 关联：[[节点]]
```

## 用户背景
- 身份：计算机技术研一新生
- 研究方向：乙烯裂解炉炉管温度检测，采用深度学习中时间序列处理方法
- 知识库领域：时间序列预测、Transformer 架构、深度学习基础

## 频率规则
- 基础巩固：每周出题
- 适度挑战：每两周出题（交替周不出）
- 前沿思考：每月出题（非本月第一周不出）
